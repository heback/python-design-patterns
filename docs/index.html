학습지 사용 방법

  1. 학습지를 열고 학번·성명을 입력한 뒤 풀이합니다.
  2. 쓰는 동안 이 브라우저에 임시 저장됩니다. 수업이 끝나면 💾 저장으로 JSON 파일을 내려받습니다.
  3. JSON 파일을 선생님이 정한 방법으로 제출합니다.
  4. 다음 시간에는 📂 불러오기로 파일을 열어 이어서 풀고, 선생님 코멘트 파일도 같은 방법으로 봅니다.

교재 목차

시작과 정리

  • 서론: OOP 원리에서 패턴으로원리를 알면서도 설계가 막히는 순간, 패턴은 무엇을 더해 주는가
  • 종합: 패턴 비교와 조합닮은 패턴을 의도로 가르고, 변경 축만큼만 패턴을 넣기

생성 패턴

  • 팩토리 메서드 (Factory Method)'언제 만들지'는 프레임워크가, '무엇을 만들지'는 하위 클래스가
  • 추상 팩토리 (Abstract Factory)함께 쓰여야 하는 객체들을, 섞이지 않게 한 번에
  • 빌더 (Builder)한 번에 만들기 어려운 객체를, 단계적으로 읽히게 조립하기
  • 싱글턴 (Singleton)'하나여야 한다'와 '어디서든 얻는다'를 떼어 놓기

구조 패턴

  • 어댑터 (Adapter)고칠 수 없는 남의 인터페이스를 우리 언어로 번역하기
  • 데코레이터 (Decorator)같은 인터페이스를 유지한 채 책임을 겹겹이 덧입히기
  • 컴포지트 (Composite)부분과 전체를 같은 질문으로 다루기
  • 퍼사드 (Facade)복잡한 서브시스템 앞에 단순한 정문을 하나 두기
  • 프록시 (Proxy)같은 얼굴을 한 대리인이 실제 객체로 가는 길을 통제하기

행위 패턴

  • 전략 (Strategy)교체 가능한 알고리즘을 객체로, 그리고 함수로
  • 옵저버 (Observer)변화를 알리는 쪽이 듣는 쪽을 모르게 하기
  • 커맨드 (Command)요청을 객체로 만들어 되돌리고, 묶고, 보내기
  • 상태 (State)행동이 상태에 따라 달라질 때, 분기 대신 객체를 바꾼다
  • 템플릿 메서드 (Template Method)절차의 골격은 한 곳에 고정하고, 달라지는 단계만 열어 둔다
  • 반복자 (Iterator)내부 표현을 감춘 채 순서대로 꺼내기, 그리고 언어가 흡수한 패턴
